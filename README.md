# Портфолио Дмитрия Литвинова

Персональный сайт Python Backend-разработчика: профиль, технологический стек, проекты, достижения и контакты.

Сайт: https://dmitry-litvinov-backend.litvinov06062006.chatgpt.site

## Структура

- `dist/index.html` — разметка, стили и интерактивные эффекты.
- `dist/assets/dmitry-profile.png` — фотография для первого экрана.
- `.openai/hosting.json` — конфигурация статического сайта для Sites.

Для локального просмотра достаточно открыть `dist/index.html` в браузере или запустить статический HTTP-сервер из папки `dist`.

Исходные сертификаты не размещены в репозитории; на сайте приведены сведения о достижениях без номеров документов.
